# Semiring source and reuse decisions

The source revision is `c00171e47d6e68d8148d7ee10c4dd77b71a97662` (Sage 11.0.beta5). Source paths are relative to that checkout.

| Decision | Evidence and rationale | Alternative considered |
| --- | --- | --- |
| Use Lean's `Nat` for the natural-number semiring | `inventory/reuse/mathlib-core.toml:lean-core.int.bignum-arithmetic` records executable natural-number arithmetic; `src/sage/rings/semirings/non_negative_integer_semiring.py` gives a Sage facade over nonnegative integers. | A new natural-number representation has no mathematical or computational need. |
| Reuse Mathlib tropical types for finite values, infinity and semiring operations | `Mathlib/Algebra/Tropical/Basic.lean` at `6d97e8ad9c32c778e7000ffda543a29488155467` defines `MinTropical` and `MaxTropical`, their addition and multiplication, and `CommSemiring` instances for a linearly ordered additive base with top. `WithTop R` and `WithBot R` add the selected infinity; `OrderDual` relates orientations. Sage's `TropicalSemiringElement` stores a finite value or `None`, but that storage choice does not justify a second Lean arithmetic. | A new tagged tropical element type would duplicate the existing Mathlib semantics and executable operations. A bare numeric value would lose infinity. |
| Reuse the lifted finite/infinity map for tropical transport | `Mathlib/Order/WithBot.lean:115` defines computable `WithBot.map`; its dual supplies `WithTop.map`. `TropicalToTropical._call_` maps finite values through target construction and maps infinity to infinity; the source doctest demonstrates integer-to-rational transport. A semiring-hom law and owner catalogue operation remain separate obligations. | Inferring a map solely from source and target types does not justify preservation of order or composition. |
| Use source algorithms for tropical matrix closure and mean | `src/sage/rings/semirings/tropical_matrix.py:Matrix_tropical_dense` cites Butkovič [But2010] Algorithm 1.6.21 for closure and §1.6.1 for Karp cycle mean; source doctests cover unbounded cycles and empty matrices. | A graph shortest-path routine does not by itself provide the matrix-valued closure contract or cycle-mean result. |
| State exact cycle means over rational bases | Sage checks a base subring of `RR` and divides by positive path lengths; exact rational inputs allow exact comparisons. Its zero-matrix branch returns infinity. A nonzero acyclic matrix reaches an empty extremum and raises an error at the baseline source; the general no-finite-cycle infinity rule is a supplemental mathematical totalization, not a Sage doctest result. | Floating point inputs need a precision/error contract that the current exact capability does not supply. |
| Place missing semantics at their owner | `inventory/capabilities/semirings.toml` records catalogue ids for natural and basic semiring operations; tropical construction, order, transport, closure and mean have no complete object/operation contract. `AGENTS.md` assigns mathematical semantics upstream and the stable language ids to the DSL owner. | Local ids or new semantics would create a competing authority. |

Reuse status and exact selectors remain in `inventory/capabilities/semirings.toml` and `inventory/reuse/*.toml`. Source doctests are selected by those records. The owner contracts above remain unresolved for implementation readiness.
